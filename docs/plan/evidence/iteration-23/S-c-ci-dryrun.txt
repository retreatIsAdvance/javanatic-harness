## 4) 前置条件核对（CI 运行环境面）

- 脚本相对路径调用依赖 **git 可执行位**：`integration/verify-consumer.sh` 本机 `-rwxr-xr-x`；
  `git add` 将按其 fs 模式记为 `100755`（CI 步骤直接以 `integration/verify-consumer.sh candidate` 调用，
  见 §1）。**提交时勿丢执行位**（`git ls-files -s` 复核为 `100755`）。
- 步骤依赖 `mvn` 在 PATH（`actions/setup-java` 的 cache maven 提供）、`JAVA_HOME` 由 setup-java 设
  （脚本按 `mvn -v` 推导 java）、`RUNNER_TEMP` 为 runner 默认环境变量。
- 网络面：隔离仓每跑每新 ⇒ 该步骤会真下载依赖闭包（本地干跑 install 1:15 min 含下载）；
  这是「只凭坐标真解析」的代价，属 B 裁决接受的漂移警报口径。
