- PRE_STEP 裁决 Enter 才采纳/落账；拒绝轮不采纳、不落账。
- 按代全量快照：首非空代落账、等代零噪声、变更代/移除 server 落账（含空代退役）。
- resume 对账：以既有账为基线，新 runtime 采纳差异代并落账。
- 账本 codec/JSONL 往返；fold 仅凭账重建注册面（注册面==最后一笔全量快照）。
- 结果上限：max=5 时 "ab你好cd" → "ab你 (output truncated)"（UTF-8 完整边界；
  success/error 同待遇）；恰等上限不截断；配置 maxResultBytes=4 生效、0 fail loud。
- 缓存：映射/归一 WARN 跨代仅一次。
