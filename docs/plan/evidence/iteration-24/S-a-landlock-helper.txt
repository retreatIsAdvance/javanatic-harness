# (e) = execvp 真把进程镜像换成 /bin/echo（限制跨 execve 继承的机制前提）。
# (f)（S-b 补录）错形状的失败方式是**静默传错参**：把 capture 布局也写进描述符、让它占住一个参数槽时，
#   绑定与 invokeExact 都不报错；原生 open 收到错位实参、静默返回 -1。六次实跑 errno 在 14(EFAULT)×3 与
#   22(EINVAL)×3 间摆动——错位槽收到什么由运行期地址决定（上行为其中一次摘录）。
#   EFAULT(14) 的归属＝**探针 (f) 故意摆错的形状**，与交付代码无关：Landlock.java 的五个形状另经 §4b
#   逐调用点 arity 审计（SYSCALL 6-long 与探针 5-long 同机制，尾部零 padding 参由 syscall wrapper 忽略）。
# 故五个形状只能靠真实调用验证：本机验证了 syscall/open/close/execvp（prctl 符号面 darwin 不存在），
# Linux 侧的真语义（rights 子集、restrict_self、真拒写）由 S-c CI 腿权威验证。

== 4b. 调用点 × 描述符 arity 逐字节审计（packet 前置；形状错的另一条静默路） ==
$ 逐 token 计数（Grep -o ValueLayout.* 于 Landlock.java 651-665 行）+ 逐调用点数实参
SYSCALL : res(long) + 6×long  ← createRuleset 6 参 · addPathBeneathRule 6 · restrictSelf 6 · queryVersion 6  ✓ 逐一相符
PRCTL   : res(int)  + 5 参    ← prctlNoNewPrivs 5 参（PR_SET_NO_NEW_PRIVS,1,0,0,0）            ✓
OPEN    : res(int)  + 3 参    ← openDirFd 3 参（path, flags, 0）                                ✓
CLOSE   : res(int)  + 1 参    ← closeFd 1 参                                                   ✓
EXECVP  : res(int)  + 2 参    ← execTarget 2 参（file, argv）                                   ✓
# invokeExact 的 arity 不符会在**运行时**抛（编译期不查）——与「静默传错参」并列的第二条形状坑，
# 故以实例计数审计落盘。SYSCALL 取 6 个 long 形（= syscall(2) 的 6 参上限），探针验的是 5 参同机制形；
# 差别的尾部全零 padding 参由 syscall wrapper 忽略（实参序不变），非语义差异。
