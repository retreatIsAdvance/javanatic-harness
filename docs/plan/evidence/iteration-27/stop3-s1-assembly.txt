## 2. 装配期发现的两个真实集成缺陷

### 2.1 classpath 通道缺 services 文件（首跑红）

首跑 `mvn -B -pl bundle/base -am test` → 4 failures + 7 errors，代表性文案：

    行引用的插件未发现: mcp-stdio

根因：mcp/stdio 只有 module-info `provides`，surefire fork 走 classpath，
ServiceLoader 只认 META-INF/services；mcp/tool 与 skill 三件均有 services 文件。
修复：新增
    mcp/stdio/src/main/resources/META-INF/services/io.javanatic.harness.kernel.plugin.Plugin
内容：
    io.javanatic.harness.mcp.stdio.McpStdioPlugin
复跑后 mcp-stdio 入发现清单，AppBootTest 22 例全绿。

### 2.2 manifest 结构化 config 不可持久化（二跑红）

二跑 `bootsBaseProfileAndManifestFlowsIntoHeader` 红：

    IllegalStateException: manifest config 'servers' for 'mcp-stdio' not primitive: ArrayList
      at JsonlPersistence$HeaderCodec.configValue(JsonlPersistence.java:580)

根因：base 行 `servers: []` 进 CompositionManifest → SessionHeader 写盘，
HeaderCodec 仅支持原语。修复：configValue/plainValue 递归支持
List/Map/null（JSON 树），非 String map 键与其它类型 fail loud。
设计判断：不把 servers 排除出 manifest——MCP server 配置影响模型可见工具面，
属 R1 组合事实；排除会静默丢事实。

新增回归用例：JsonlPersistenceTest#manifestConfigRoundTripsNestedValues
（servers[] 内嵌 args[] 与 env{}；钉盘上树形 + 重载 manifest 等值）。
注意：Map.copyOf 不承诺键序，盘上断言只钉树形（数组/对象两层），不钉字段序。

### 2.3 新用例突变检查

突变：HeaderCodec 的 List 分支改为 `throw new IllegalStateException("mutation: list unsupported")`
