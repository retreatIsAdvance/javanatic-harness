== 1. 命名归一（T2 增补）==
规则（纯函数，McpToolPlugin.publicName）:
- serverId 配置面拒 '__'（McpServerConfig，fail loud；配置面维持）；
- raw 合法（非空、无 '__'、仅 [A-Za-z0-9_-]、mcp__<server>__<raw> 总长 ≤ 64）→ 原样；
- 否则非法字符→'_'、折叠连续 '_'、去首尾 '_'、按预算截断，追加 '_' + hash8
  （sha256(serverId '\0' rawName) 前 8 hex）+ WARN；清洗为空退化为 "tool"；
- catalog 条目直接记录 publicName（fold 不重跑算法）；读侧缺 publicName fail loud。

钉死向量（shasum -a 256 独立核验）:
$ printf 'beta\0a__b' | shasum -a 256 | cut -c1-8
ff2d9f4e  → mcp__beta__a_b_ff2d9f4e
$ printf 'alpha\0My Tool.v2' | shasum -a 256 | cut -c1-8
4d1308b1  → mcp__alpha__My_Tool_v2_4d1308b1
$ { printf 'alpha\0'; printf 'x%.0s' {1..80}; } | shasum -a 256 | cut -c1-8
1cca3f0b  → 64 字符，前缀 mcp__alpha__、后缀 _1cca3f0b

覆盖用例:
- McpToolPluginTest#dunderRawNamesNormalizeDeterministicallyAndRemainCallable
  （WARN 文案 + 注册名 + 调用桥回 raw 名）
- McpToolPluginTest#publicNameIsPureBoundedAndFailLoudOnImpossiblePrefix
  （合法原样 / 非法清洗 / description/schema 无关 / 长度 64 / 超短 server 预算 fail loud /
   serverId '__' fail loud）
- McpStdioPluginTest#doubleUnderscoreRawNameIsAcceptedAtTransport（transport 不再拒 raw '__'）
- McpCatalogLedgerTest#codecRejectsPreNormalizationLedger（旧账缺 publicName fail loud）

== 6. 大输出上限的诚实登记（不宣称不存在的统一限额）==
- transport 读路径对 1 MiB 单帧无截断（上测）；
- ToolExecutor 没有通用结果字节上限；fs/shell 的 maxReadBytes/maxOutputBytes 是
  各自 Provider 的上限，不适用于 MCP 结果；
- 因此「大输出走既有输出限额」的初稿措辞不成立，已在 iteration-27 偏离表登记；
  统一 MCP 结果字节上限挂 it27.1（与 Streamable HTTP 合并设计）。
