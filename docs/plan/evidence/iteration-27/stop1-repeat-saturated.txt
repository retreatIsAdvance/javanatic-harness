# it27 停 1 取证 — CPU 饱和重复跑（宿主机 `yes` 打满；2026-10-15）

口径（it25/it26 惯例）：时序敏感的测试在 CPU 饱和下重复跑；每轮**即时**快照 surefire counts（报告文件被下一轮覆写，统一 grep 会读到覆写后数据——逐轮快照才能证明真实重跑）；计时有差异 = 确实每轮新跑。

每轮：`yes > /dev/null &` ×4 → `mvn -B -q -pl mcp/stdio -am test` → 逐轮 counts 快照。三轮 34/34 全绿（16/4/10/4），计时互异：
