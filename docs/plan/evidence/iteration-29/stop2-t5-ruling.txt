主代理落实口径（不是新增用户原话）
1. T5 已裁：自有边界实现，不引入 LSP4J 或任何新第三方依赖；本裁决归档后写进 iteration-29.md T5 行与停 2 设计。
2. 边界 1（JsonRpcPeer 每 transport 私有）：lsp/jdtls 内复制并按 LSP 帧语义改写，不建跨协议共享模块；设计注记「若第三个消费者出现可重访抽取」。mcp/stdio 的按行帧与 LSP 的 Content-Length 字节帧不共 transport、不共解析器。
3. 边界 2（LSP 边界义务）：Content-Length 按字节数、charset 恒 UTF-8；Content-Length 畸形 = 流级断裂（沿 mcp/stdio 分层先例，不挽救、不回写）；server 发起请求必须全部应答——停 0 实测 412 帧、18 个请求已答、尾流 id19 未答在探针可容忍，产品客户端不可容忍。
4. 边界 3（偏离清单升格为客户端验收矩阵）：停 0 四项偏离（shutdown {} 非 null、progress 早于 initialized、无 version 诊断、退出尾流请求）逐项映射「客户端处理 + 测试」，从披露升级为对照验收。
5. pits.md 通则（verbatim 捕获文件需 `-text !eol` + whitespace 豁免，SHA 对账为检测面）挂收口批，本批不混入。
6. 下一步按用户指令：落盘停 2 设计（模块布局 lsp/jdtls、生命周期矩阵、四态真机区分、措辞纪律、偏离对照表）→ 动 Provider 代码；push 仍无授权、不入本批。
