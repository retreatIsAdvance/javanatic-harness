4. Protocol deviations and journal scope
initialize 响应前：progress/create id1–7、对应 $/progress、language/status；本模板无 initialize workDoneToken。依据固定 LSP3.17 研究，属于需披露的初始化顺序偏离。探针继续回复早期服务端请求以观察候选，不自动批准未来兼容策略。
seq409 shutdown：id4，无 params。
seq411 shutdown response：result={}，非规范 null；原帧未归一化。
seq412 exit；随后只排空字节，不再由 Peer 处理请求。
protocol.txt 共412条带 seq/单调时间的 JSON 语义记录，不是全程 wire 字节存档。
stdout-after-shutdown.txt 保存 raw_hex，共1209bytes；protocol-tail-analysis.txt 派生解码7条完整消息：3条日志 + progress/create id="19" + begin/report/end。
journal 内18个 server request 均回复；尾流另1个 id="19" 未回复。总观察到19个，不得把 facts-summary.txt 的 server_request_counts=18 当全流计数。
尾流混合 shutdown response 时已有 peer.buffer 与后续读取，缺逐帧时间；不能断言所有尾流都在 exit 后才发送。
尾流无未消费字节不等于协议语义全部收敛；本次进程退出成功不豁免未来 Provider 的收尾策略。
