# 0.5.0 发布验收 · 稳定面差异审计（v0.4.0 → 0.5.0 树）

核对基准 = [12-api-stability.md](../../design/12-api-stability.md) §7 三法固化：导出面 =
module-info.java 扫描；配置键 = 插件 config 读取点 / base bundle；CLI = `jh --help` /
`--verify`。本次在 v0.4.0 发布面（67 坐标）与 0.5.0 树之间逐项比对，2026-11-18 执行。
发布执行属用户侧；本档承载验收证据。收尾批（bump `0.6.0-SNAPSHOT` 等）不改任何主源
语义，不影响比对；版本串同步见文末观察项。

  消费，jlink 镜像须含该 JDK 模块）。既有 51 叶 + 16 pom-only 的 module-info **零改动**。
- `session/persistence` 包（既有导出）**新增类型** `SessionTail`（71 行纯增量）——

## 观察项（如实记录，非缺陷）

- **对外版本标识串滞后一格**：0.4.0 发布件 UA 为 `javanatic-harness/0.3`（0.5 开发期
  才补到 0.4）；本次 0.5.0 发布件 UA 为 `javanatic-harness/0.4`、JDT clientInfo 为
  `0.4.0`。二者均为出站标识串、不进 API 稳定面；收尾批已同步为 `0.5` / `0.5.0`
  （主源 + 测试断言），下个发布周期起随翻转批同步——与 0.4.0 同类漏网的复发，记观察。
- 第三方依赖新坐标 JLine 4.6.0 三件套（it34）如实入 release notes；native 不可排除。

## 结论

**零破坏性变更**。全部为纯增量：4 新模块 / 3 新导出包 + 1 既有包新增 seam 类型、
+7 CLI flag、零新事件、零新配置键、零 base bundle 行变化。既有稳定面（导出包增删 /
SessionEvent permits / 既有 CLI flag / 既有 config 键）零破坏，0.4.x 无补丁义务。
