## 一、首次尝试失败与恢复（pinentry）

- 首次运行：`FAILURE [4.151 s]`，`harness-parent` 项目 `maven-gpg-plugin:3.2.8:sign (sign-artifacts)` 退出码 2。
- 断口原文：`gpg: 签名时失败： 缺少 pinentry`（gpg 2.5.21）。
- 现场核查：`~/.gnupg/gpg-agent.conf` 已配 `pinentry-program /opt/homebrew/bin/pinentry-mac`；`pinentry-mac (pinentry) 1.3.1.1` 可执行；`GPG_TTY`/`DISPLAY` 均未设（无 TTY 上下文）。
- 处置（0.3.0 在同一环境下的恢复预案）：`gpgconf` 重启/重载 agent + 探测签名。探测签名（`gpg --yes --detach-sign /tmp/it37-gpg-probe.txt`）即刻 `PROBE_EXIT=0` 并产出 .sig——pinentry-mac 走 macOS 钥匙串解锁，未弹手输框，热缓存就绪。
- 恢复后重跑 deploy：签名阶段 76 处 `Signer 'gpg' is signing ...` 全部通过，`signing failed` 计数 0。
