## 失败闸的静态事实（不是口头承诺）

```text
$ grep -rn "implements WebSearchService" web/search-deepseek/src/main
DeepSeekSearchProvider.java:40:final class DeepSeekSearchProvider implements WebSearchService {
```

- 模块内只有这一个 `WebSearchService` 实现；没有第二 provider、没有重试/换源代码。
- 主源码无 HTML 解析/正文抓取：`grep -rniE "fallback|scrap|html"` 仅命中配置默认值
  `intValue(..., int fallback, ...)`，不是网络降级路径。
- 探针失败时 `catch (WebException)` 打印
  `PROBE_FAILED code=... observed=... detail=...` 后原样抛出；测试断言失败即红，
  不存在“失败后换一条路继续”的分支。
