## 1. 状态行与头区

- `parsesStatusAndHeadersWithOwsAndDuplicates`：`Content-Type:  text/plain ` 去 OWS；
  `Set-Cookie` 重复值保序；头名大小写不敏感。
- `acceptsNon2xxStatusAsAResult`：503 是结果（客户端侧 `non2xxIsAResultWithBody` 再证 404 带正文）。
- `rejectsMalformedStatusLines`：HTTP/2、ICY、1xx（100 Continue、**101 Switching Protocols**）、
  非数字、999、空响应全部 `WEB_NETWORK_ERROR`。状态行接受 `HTTP/1.0` 与 `HTTP/1.1` 的
  2xx–5xx；101 属“客户端未请求升级”的传输层拒绝路径，不作为结果透传（评审补测，M9）。
- `rejectsObsFoldAndBadHeaderShapes`：折行、非法头名、控制字符、无冒号均拒。
- `enforcesHeaderCountAndSizeBounds`：>100 头；头区 >64 KiB；单行 >8 KiB。
- `requiresStrictCrlf`：裸 LF 与裸 CR。
- `rejectsSmugglingShapesAndInconsistentLengths`：CL+TE 同时出现、TE 非 chunked、
  不一致 CL、`+4` 非数字 CL；`acceptsIdenticalRepeatedContentLength` 允许相同重复 CL。
- `noBodyStatusesIgnoreFramingHeaders`：204/304 不读体，即使带 CL/TE。
- `readsContentLengthBodyAndRejectsShortBody`：短体（声明 10 实际 5）→ 截断协议错。

## 2. chunked 解码（T2 条件 ①）

正向：

- `decodesChunkedWithExtensionsAndTrailers`：`4;foo=bar` 扩展被忽略；0 块后 trailer 读到空行；正文拼接正确。
- `decodesUppercaseHexChunkSize`：`A` 十六进制大小写均可。
- `chunkedExactlyAtCapIsNotMarkedTruncated`：恰好到达上限不置截断（边界不误报）。
- `chunkedOverCapStopsAndMarksTruncated`：超上限停收、保留前缀、`truncated=true`（不报错）。

负向（同一用例 `rejectsMalformedChunkFraming`）：

| 输入 | 期望 |
|---|---|
| `ZZ` / 空行 | 坏 chunk size |
| `4\r\nabc` | 块内截断（`truncated`） |
| `4\r\nabcdX\r\n...` | 数据后非 CRLF（`chunk data is not CRLF-terminated`） |
| `4\r\nabcd\n\n0\r\n\r\n` | 数据后裸 LF（`chunk data is not CRLF-terminated`；本停点新增用例，专杀“跳过 CRLF 校验”） |
| `4\r\nabcd\r\n` | 缺 0 块（截断） |
| `0\r\n bad-fold\r\n\r\n` | trailer obs-fold 拒 |
| `0\r\nX: v` | trailer 未终止（截断） |
| 17 个十六进制字符 | size 溢出/超长 |
| 8200 字节 size 行 | 超 8 KiB 行界 |
