三、真实公网抓取与负例矩阵（jlink jh 驱动）
------------------------------------------------------------------------
驱动方式：/tmp 下的假 OpenAI 兼容 SSE 服务（不入仓）——首个请求返回一个
web_fetch tool_calls 增量，URL 取最后一条 user 消息中的 https?:// token；
第二个请求（messages 含 role=tool）返回 finish_reason=stop 的文本。
每条命令形如：

  env -u DEEPSEEK_API_KEY JDK_JAVA_OPTIONS=-Duser.home=/tmp/it28-s3/home2 \
    dist/jh/target/jlink-image/bin/jh "<任务文本含 URL>" \
    --provider=fake --model=fake --base-url=http://127.0.0.1:18766 \
    --api-key=fake-key --workspace=/tmp/it28-s3/ws --approval=auto < /dev/null

说明：一次性模式的 stdout 只渲染助手最终文本（本矩阵统一为 TOOL-FED-BACK），
工具结果经 executor 落进会话日志（tool/call + tool/result）——以下内容逐字录自
隔离 home2 的 log.jsonl，未二次加工。

用例 5 · 重定向目标为私网（拒绝）
  tool/call: {"url": "https://httpbin.org/redirect-to?url=https%3A%2F%2F127.0.0.1%2F"}
  tool/result.isError: true

  注：首跳 httpbin.org 是公网、TLS 正常，拒绝发生在**重定向目标**的地址闸——
      跨源重定向没有绕过公网校验（B17）。

用例 6 · 重定向降级到 http（拒绝）
  tool/call: {"url": "https://httpbin.org/redirect-to?url=http%3A%2F%2Fexample.com%2F"}
  tool/result.isError: true
  WEB_REDIRECT_BLOCKED: url must use https (got: http)

六条用例 EXIT 均为 0（turn 正常结束；工具错误作为 tool/result 回灌模型，
不改变 turn 退出码——错误码是稳定词表，不是进程崩溃）。
