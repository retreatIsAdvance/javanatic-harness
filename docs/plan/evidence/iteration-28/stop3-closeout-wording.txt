------------------------------------------------------------------------
一、裁决原文（停 3 评审 §二.2）
------------------------------------------------------------------------
「把 `web_search` 结果头的措辞改为只陈述实际存在的字段（无 snippet 时不出现
snippet 措辞，或在来源行标注 `snippets: 0`）——工具不该诱导模型说出数据不支持
的来源声明。」

------------------------------------------------------------------------
二、改动
------------------------------------------------------------------------
1. 工具描述（WebToolPlugin.SEARCH_DESCRIPTION）：
   旧："Search the web and return cited sources (title, URL, snippet). ..."
   新："Search the web and return cited sources. Each source lists its URL plus a
        title and snippet when the provider supplies them. ..."
   —— snippet 从「固定字段」改为「provider 提供时出现」的条件事实。

2. 搜索结果显示头（WebToolOutput.renderSearch）：
   在 Provider / Query 之后、编号来源之前新增一行：
     Sources: N (titles: x, snippets: y)
   - N = 来源条数；x = 实际带标题的来源数；y = 实际带 snippet 的来源数；
   - 只陈述实际存在的字段：零 snippet 时显式 `snippets: 0`，不再让格式暗示
     snippet 字段存在；
   - 零来源仍是 `No sources returned`（不追加计数行）；
   - 该行同样受输出帽约束（超帽时按 UTF-8 边界截断并追加标记）。

3. 用例：
   - 新增 searchHeaderStatesZeroSnippetsWhenProviderSuppliesNone：
     两条来源均无 snippet → 断言 `Sources: 2 (titles: 2, snippets: 0)` 且
     结果不含 `Snippet`；
   - 新增 searchHeaderCountsOnlyFieldsActuallyPresent：
     一条无标题无 snippet、一条两者皆有 → 断言
     `Sources: 2 (titles: 1, snippets: 1)` 与来源行内容；
   - 既有 searchRendersProviderQuerySourcesTruncationTailAndSummary 同步断言
     `Sources: 2 (titles: 1, snippets: 1)`；
   - toolsAreApprovalRequiredAndSingleField 增加描述断言
     `contains("when the provider supplies them")`。
