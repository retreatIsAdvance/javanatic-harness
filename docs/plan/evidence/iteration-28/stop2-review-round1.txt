## 二、两处自主收口——都批，且各有可表扬处

1. **M7 自指测试的自我捕获**：突变时把测试常量一起改大 → 用例恒过 →「突变未红」。这是突变测试的经典陷阱（测试与被测共享魔法值），主动识别并改为**字面量钉死**——这个自捕比七杀本身更有价值，建议把「突变不得触碰测试内的对应常量」写进突变惯例（AGENTS 或证据档模板一句话）。
2. **16 KiB 错误体专用截断（M11）**：真缺陷预防——非 2xx 大错误体原本会走通用 1 MiB 上限错误、**丢掉状态码**，违背「消息含状态码 + 有界 provider 文本」契约。修正 + 钉死。收口批在 05/07 的错误消息契约节补一句「错误体 16 KiB 截断」。

## 三、残余风险——我方确认意见

- **搜索端点不过公网闸**：**设计正确**。公网闸保护的是「不可信网页内容」的抓取面；`api.deepseek.com` 是认证 provider API，二者威胁模型不同。而搜索返回的来源 URL 只是**数据**（给模型的引用），`web_search` 不抓取它们——将来模型若 `web_fetch` 某来源，那次调用自然过全闸。层次清晰，无需改。
- **来源 URL 仅校验非空白**：同上，作为数据展示合法；已列入 packet §6 即可。
- **ResponseObserver 包内测试缝**：默认 no-op 可以，但给它立个界——**不得演化为生产回调面**（脱离测试缝定位就要回来评审）。

## 四、真跑与流程

- 探针 `PROBE_OK`（200 / 62,461 B / 5 来源 / 8.4s），共耗 3 次请求（含补丁前复跑）——配额消耗如实申报；
- 11 杀全红 + 逐字节还原 + 零残留；默认态探针 skip（keyless 纪律双态并行）；
- zsh `status` 只读变量中断导致 M1 残留 → 定位还原——过程如实，且这正是「突变后必须 grep 残留 + shasum 对照」纪律要防的事故类型，纪律起了作用。
