------------------------------------------------------------------------
二、live 腿断言（先证“真的发生了”）
------------------------------------------------------------------------
手装最小组合（session-store / jsonl 持久化 / agents / loop-guard / system-prompt /
llm / approval-auto / tools / fake-web-fetch / web-tool / replay / agent-loop），
replay 模型脚本 turn1 发 web_fetch("https://example.com/page")，turn2 收尾。

断言：
- fake 抓取 provider 恰被调用 1 次（liveFetch.calls() == 1）；
- 工具结果首行 == 信任前缀常量；
- 结果含最终 URL（https://example.com/final）、Status 200、
  Content-Type: text/html; charset=utf-8、Truncated: false；
- HTML 经提取器转文本：含 "# Replay" / "Body text"，**不含**脚本体 "bad()"
  （<script> 整块被剔除）；
- 事件类型集合 noneMatch(startsWith("web/"))，且含 tool/call + tool/result
  —— **零新事件**；
- 唯一的 tool/call 名恰为 web_fetch；
- 存盘（SessionPersistence.save）。

------------------------------------------------------------------------
三、replay 腿断言（新 Runtime 只载盘）
------------------------------------------------------------------------
- 工具结果按原样入账：JSONL 往返后 content 与 live 逐字相等；
- 事件序列 containsExactlyElementsOf(liveEvents)（含顺序）；
- 两个 LlmRequestEvent 锚点上做**前缀折叠重建**：
    Session.create(id, events.subList(0, i), header)
  → prompts.assemble(folded) 含信任前缀段，
    sha256(assembled) == anchor.systemPromptSha256()（系统提示词含 Static(70) 段）；
    sha256(toolSchemaFingerprint(registry.schemas)) == anchor.toolsSchemaSha256()
    （工具 schema 集合稳定，含 web_fetch）；
- 回放路径 **fake provider 零调用**（replayFetch.calls() == 0）——抓取只来自日志，
  没有任何网络动作。
