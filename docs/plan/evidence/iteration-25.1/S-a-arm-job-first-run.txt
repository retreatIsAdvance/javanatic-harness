红根因（同日志逐字）——侦察 delta 自身形态缺陷（pwsh 点号截断的又一实例）：
  ##[group]Run mvn -B -ntp package -Dmaven.test.failure.ignore=true
  shell: C:\Program Files\PowerShell\7\pwsh.EXE -command ". '{0}'"
  env: JAVA_HOME: C:\hostedtoolcache\windows\Java_Microsoft_jdk\25.0.3\aarch64
  [INFO] Javanatic Harness .................................. FAILURE [  0.002 s]
  [ERROR] Unknown lifecycle phase ".test.failure.ignore=true". You must specify a valid lifecycle
          phase or a goal in the format <plugin-prefix>:<goal> ...
  ⇒ pwsh 把未加引号的 `-Dmaven.test.failure.ignore=true` 在首点处截成两段：`-Dmaven`
    （被 maven 按 -Dmaven=true 吃下）+ `.test.failure.ignore=true`（被当生命周期阶段 ⇒
    LifecyclePhaseNotFoundException）；0.002s 即死 = 任何模块编译之前。
    与 it25 五跑 `-Dstderr` + `.encoding=UTF-8` 同族（AGENTS.md 已知坑 pwsh 条）。
  ⇒ 产品/测试面**未触**：红在 CI 脚本命令行解析层；landing 形态（`mvn -B -ntp package`，
    与 windows x64 腿逐字同形）**零裸 -D token**——全 ci.yml 核过：run: 行上唯一裸 -D = 本行
    侦察 delta（其余 -D 或在 bash 步 [line 52]、或在 pwsh 数组 splat [lines 172/303]、或为
    -DestinationPath/-Directory 的 grep 误匹配 [lines 245/246/373/374]）。
  ⇒ 侦察面价值核算：setup-java 装配（F1）已验绿；测试清单面未收（Build 未到编译）——
    「一次收全清单」的收益本轮未兑现。

待裁（随 packet）：R1 = 修 quoting（单引号 `'-Dmaven.test.failure.ignore=true'`）→ 侦察三跑、
收全测试面（初判推荐——裁决序列本意即先收全清单）；R2 = 直接摘旗标、scratch 并回 master →
真跑（fail-fast；在 VM 全 reactor 绿 + x64 腿绿的既证面下可接受，省一轮）。
