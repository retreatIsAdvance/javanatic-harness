## 二、核对三法重跑

1. **导出面**：既有 31 叶模块的 module-info.java 在 v0.2.0..master 零改动（改动只落在
   新模块 skill×3 / mcp×4 / web×4 / lsp×3 与 examples/headless——后者不在发布面）。
   既有导出包零增删；新增导出包 14 个全部随新模块入场。12 §2 表（2026-11-02 复测
   47 模块 / 51 包）与本次 diff 审计互证一致，无漂移。
2. **事件 schema**：`SessionEvent` sealed permits 零变化（core/session 仅 pom 翻转）；
   新事件全部走 `ExtensionEvent` + codec SPI（skill/catalog、mcp/catalog）。
   `PreStepDecision` / `LoopGuard` 等 agentloop seam 类型零变化。
3. **配置键**：既有插件 id 的 config 键零变化（读取点模块均无源码改动）；新键全部
   属新插件（skill-local/skill-tool、mcp-stdio/mcp-http/mcp-tool、web-fetch-http/
   web-search-deepseek/web-tool、lsp-jdtls/lsp-tool），12 §5 表已逐键记账。
4. **CLI**：bundle/headless 零源码改动 → 冻结 flag 面与 0.2.0 逐字节同源。实测
   `jlink-image/bin/jh --help` EXIT=0，旗标与 12 §6 清单逐项对齐，无新增 flag；
   `--verify` EXIT=0，治理摘要 `30 rows, 37 discovered, 0 unreferenced`
   （与现状卡 30/37/0 一致；keyed 档 32/37 未跑——keyless 即验收口径）。

## 三、破坏候选：ValueSchema.Opt（唯一，需 release notes 声明）

`tools` 导出包内 sealed 接口 `ValueSchema` 新增 `Opt` 变体（it27 停 2，可选字段
缺失放行语义；wire 侧零变化——解包直写内层 schema）。对穷尽 switch 的消费者是
源码破坏（编译期新增 case 义务），运行时零影响。0.2.0 已发布消费者按 §1 语义：
破坏性变更随 0.3.0 次版本发布，release notes 声明迁移路径 = 为
`ValueSchema.Opt` 补 case（解包 `opt.schema()` 按内层校验或显式跳过）。

其余全部为纯增量：新包、新公开方法（ToolArgs.rawJson/readOptionalLong、
ConfigValues.masked/isSensitiveKey）、新配置键、新插件行、新扩展事件——均不破
0.2.0 面，0.2.x 无补丁义务。
