0.3.0-rc1 排练：版本格式锚修复取证
====================================

一、暴露过程
------------
块 B push（commit 77d9340 + tag v0.3.0-rc1）被 pre-push 钩子拒绝：
钩子执行 `mvn -B -q package`（与 CI 同口径全量构建 + 全部测试），
在 harness-examples-headless 红于
  HeadlessOptionsTest.versionConstantIsBuildInjected
  Expecting actual: "0.3.0-rc1" to match pattern: "\d+\.\d+\.\d+(-SNAPSHOT)?"

根因：`versions:set -DnewVersion=0.3.0-rc1` 改变了构建期注入的版本串，
而测试的格式锚只承认 release / SNAPSHOT 两种形态。纯测试面缺陷，
产品代码零改动；影响面 = rc 版本本地推不出去 + 该 tag 的 CI 四腿必红。

二、修复
--------
文件：examples/headless/src/test/java/io/javanatic/harness/examples/headless/HeadlessOptionsTest.java
  - 原锚：\d+\.\d+\.\d+(-SNAPSHOT)?
  + 新锚：\d+\.\d+\.\d+(-SNAPSHOT|-rc\d+)?
Javadoc 同步半句：「rc 排练版本同样合法」。锚的防未过滤/空资源漂移原意保留
（`${project.version}` 与空串仍不匹配）。
