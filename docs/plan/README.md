# 迭代验收清单（plan/）

每迭代一个 `iteration-N.md`：四确认（内容 / 目标 / 为什么 / 不做）+ 验收清单（勾选 + 证据）。
**落盘是开工的前置条件**；验收项全部勾选且证据在案（实际执行的命令与结果）才进入下一迭代——对应 AGENTS.md「迭代仪式」与「证据匹配改动面」。

## 生命周期

草稿（四确认达成时填写）→ 进行中（逐项勾验收）→ 已完成（证据齐、验收后修正记录在案）

## 与其他工件的关系

- `docs/design/`：目标态——是什么、为什么这样设计
- `docs/plan/`：逐迭代的范围承诺与验收状态——做没做、验没验
- 未来 `.agents/notes/`：决策史——为什么改（AGENTS.md「修改本文件」的阈值触发时启用，不要把决策史写进本目录）

## 模板（复制到 iteration-N.md）

```markdown
# 迭代 N — <名称>（<状态：草稿/进行中/已完成>）

模块：<涉及模块>

## 四确认
- 内容：
- 目标：
- 为什么：
- 不做：

## 验收（证据 = 实际执行的命令与结果）
- [ ] …

## 验收后修正（如有）
| 提交 | 缺陷 | 修正 |
|---|---|---|
```
